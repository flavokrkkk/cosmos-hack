# Как читать контрольные выгрузки

[Расшифровки всех обозначений, столбцов и единиц измерения](../docs/22-hybrid-selection.md#словарь-результатов).

- `portfolio_detail.csv` — экономика каждого выбранного лота после применения режима.
- `constraints_BASE.csv`, `constraints_STRESS.csv` — порог, факт, запас и PASS/FAIL для каждого ограничения.
- `sensitivity_BASE.csv`, `sensitivity_STRESS.csv` — запас до нарушения ограничений при изменении одной группы входов.
- `portfolio_space.csv` — все рассчитанные сочетания лотов и режимов, включая не прошедшие ограничения; порядок строк не является рейтингом гибрида.
- `portfolio_metrics.json` — итоговые показатели выбранного портфеля.
- `hybrid_analysis.json` — Q, Δ, шкалы и объяснение выбора.
- `export_manifest.json` — хеши входов, реализации и результатов для воспроизведения экспорта.

Единицы денежных потоков — млн ₽/год, стартовых затрат C0 — млн ₽ единовременно. VPUB не является денежными поступлениями; KCASH не является прибылью. Подробности — в справочнике по ссылке выше.
