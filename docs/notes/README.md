# Заметки (датированные)

_База знаний Кейса 02 · [← индекс](../README.md)_

Сюда — брифинг по кейсу, стендапы, консультации с экспертами и трекерами, разборы. **Один файл —
одно событие:** `YYYY-MM-DD-<тема>.md` (например `2026-09-11-briefing.md`).

Шаблон заметки:

```
# <Событие> — <дата>
Кто / когда / где.
## Что сказали (ФАКТ; важное — дословно)
## Что решили → перенести в 05-decisions.md
## Что обновить в docs (список файлов и что именно)
## Открытые вопросы
```
