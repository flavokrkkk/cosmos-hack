## Как пользоваться

- **Обоснование режима доступа / финансирования / риска на лот** → `intl-procurement-models.md`
  (таблицы 4.3.1–4.3.3, формулировки 4.3.6) + `ru-service-model.md` (российский инструмент под каждый).
- **Обязательные цифры модели** → официальный CSV/config, ссылки в `engine-parameters.md`.
  `lot-economics.md` содержит внешние аналоги до брифинга и не заменяет синтетические входы.
- **Статьи из комплекта** → `case-literature.md`: содержательное обоснование, не подмена коэффициентов.
- **Язык защиты и ожидания жюри** → `kep-case-holder.md` («Что это значит для нашего решения»).
- **Ссылка в отчёте** → `sources.md` или inline-URL в соответствующем файле.

## Что даёт ресерч и чего он не подтверждает

1. Материалы КЭП дают контекст позиций кейсодержателя. **ГИПОТЕЗА** о составе жюри проверяется
   по официальному объявлению; состав совета организации сам по себе её не подтверждает.
2. Каталог механизмов закупки и финансирования даёт кандидатов для обоснования. **ГИПОТЕЗА**
   применимости каждого механизма проверяется по условиям лота и актуальным первоисточникам.
3. Числа показывают порядки величин. **ГИПОТЕЗА** их применимости к конкурсным лотам проверяется
   по паспорту и границам модели. Внешние аналоги не подтверждают восемь предполагаемых лотов.
