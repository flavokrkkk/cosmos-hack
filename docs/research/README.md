## Как пользоваться

- **Обоснование режима доступа / финансирования / риска на лот** → `intl-procurement-models.md`
  (таблицы 4.3.1–4.3.3, формулировки 4.3.6) + `ru-service-model.md` (российский инструмент под каждый).
- **Цифры в модель и в отчёт** → `lot-economics.md` (таблица + пояснения) → `engine-parameters.md`.
- **Язык защиты и ожидания жюри** → `kep-case-holder.md` («Что это значит для нашего решения»).
- **Ссылка в отчёте** → `sources.md` или inline-URL в соответствующем файле.

## Что «больше, чем гипотеза» (кратко)

1. Кто оценивает и как думает — известно (люди, цитаты, их собственные аналитические позиции).
2. Под все четыре группы решений есть **готовые российские инструменты** с номерами статей законов.
3. Экономика лотов оцифрована из первоисточников — модель не будет «на выдуманных числах».
