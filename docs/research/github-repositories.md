## Решения других команд

### [pmixay/hackathon-1109](https://github.com/pmixay/hackathon-1109)

**НАХОДКА (повторный поиск 12.09.2026):** новое для нашей подборки точное
совпадение. В [README](https://github.com/pmixay/hackathon-1109/blob/0b5e0079f534731bfbf4196042429de9ab7cfede/README.md)
команда прямо указывает выбранный Кейс 02 «Космос как инфраструктура».
Проверенное состояние —
[`0b5e0079`](https://github.com/pmixay/hackathon-1109/commit/0b5e0079f534731bfbf4196042429de9ab7cfede).

- **НАХОДКА:** есть [веб-инструмент](https://github.com/pmixay/hackathon-1109/blob/0b5e0079f534731bfbf4196042429de9ab7cfede/app/README.md)
  на Python и JavaScript: портфель, сравнение, запасы ограничений в STRESS,
  предложения замены и экспорт результатов. Отдельно присутствует расчётный
  пакет `src/kosmo/`, конфиги, тесты и материалы записки.
- **НАХОДКА:** [модель выбора](https://github.com/pmixay/hackathon-1109/blob/0b5e0079f534731bfbf4196042429de9ab7cfede/docs/note/02-selection.md)
  использует взвешенную сумму нормированных критериев на множестве
  STRESS-допустимых вариантов. Авторы выбирают `FIRE:A + AGRI:B + TRANS:B + ENV:A`
  управленчески и прямо пишут, что это не первый вариант в их рейтинге.
  Полезная тема для изучения — обоснование компромисса между общественной
  ценностью и денежными показателями, а не только реализация перебора.
- **Ограничение:** исходники и документация просмотрены, приложение и тесты
  не запускались. Заявленные авторами число тестов, места в рейтинге и
  численные результаты независимо не подтверждены. Наличие `cases/case01/`
  не делает проект решением Кейса 01: README явно фиксирует выбор Кейса 02.

**НАХОДКА (повторный поиск 12.09.2026):** ещё одно точное совпадение по нашему
кейсу; авторы называют команду «STAR labs». Проверенное состояние —
[`02c127b5`](https://github.com/whatrushki/cosmo-inf/commit/02c127b5102a9f6857b8db78cd31e411b09af62b).
Источник самоописания:
[README](https://github.com/whatrushki/cosmo-inf/blob/02c127b5102a9f6857b8db78cd31e411b09af62b/README.md).

- **НАХОДКА:** [React-приложение](https://github.com/whatrushki/cosmo-inf/blob/02c127b5102a9f6857b8db78cd31e411b09af62b/src/App.tsx)

  `FIRE:A + AGRI:C + TRANS:C + ENV:A`. Есть Python-ядро и резервное Streamlit-приложение.
- **НАХОДКА:** опубликованы
  [исходник управленческой записки](https://github.com/whatrushki/cosmo-inf/blob/02c127b5102a9f6857b8db78cd31e411b09af62b/docs/management_note.md),

  и [HTML-презентация](https://github.com/whatrushki/cosmo-inf/blob/02c127b5102a9f6857b8db78cd31e411b09af62b/presentation.html).
  Наличие файлов подтверждено деревом репозитория; аудит их содержания и PDF
  в рамках поиска не проводился.
- **Ограничение:** фразы README «победное решение» и «100 из 100 баллов» —

  `t_rep` как тиражируемость; эту трактовку не переносим в наш проект —
  см. [официальные ограничения терминологии](../01-case02-brief.md).
  Приложение, сборка, тесты и численные результаты здесь не проверялись.

**ФАКТ:** у обоих новых репозиториев GitHub API возвращает `license: null`:

[whatrushki](https://api.github.com/repos/whatrushki/cosmo-inf).
Чужой код и конкурсные материалы в наш проект не переносились.

## GitVerse

**НАХОДКА (ограниченный отрицательный результат):** внешний поиск
`site:gitverse.ru` по названию кейса, «Космос как инфраструктура»,
«космохакатон», `cosmo`/`kosmo` и именам файлов комплекта не дал подтверждённых
репозиториев нашего Кейса 02. Это не доказывает их отсутствие.

**Ограничение проверки 12.09.2026:** прямое обращение к
[каталогу GitVerse](https://gitverse.ru/explore/repos) и `api.gitverse.ru`
из рабочей среды завершалось таймаутами; Chrome также показал
`ERR_TIMED_OUT`. Через веб-поиск доступны отдельные индексированные страницы,
но внутренний поиск репозиториев полноценно проверить не удалось. По
[документации GitVerse](https://gitverse.ru/docs/gitverse/basics/quick-start/explore/)
публичный поиск доступен без авторизации; наблюдаемая проблема — доступность
сайта из этой среды, а не установленное требование входа.

**НАХОДКА (повторная проверка 12.09):** каталог снова доступен через инструмент
веб-поиска, но прямой HTTPS-запрос из рабочей среды вновь завершился
`SSL connection timeout`. Внешние запросы по «Космос как инфраструктура»,
«космохакатон» и `case_core` новых подтверждённых совпадений не дали.
Полноценный внутренний поиск GitVerse по-прежнему не проверен.

## Как искали

Проверены:

- поиск репозиториев и коммитов GitHub по точному названию кейса, АНО «КЭП»,
  формулировкам «4 из 8», «общественное ядро», «режим доступа», названиям и
  кодам лотов, именам файлов официального комплекта;
- варианты `cosmohack`, `kosmohack`, `COSMOHACK26`, `space economy`,
  `space portfolio` среди репозиториев, созданных 10–12.09.2026;
- внешняя выдача `site:github.com`, публичные форки официального репозитория и
  ссылки в публичных анонсах серии.

В углублённом проходе добавлены GitHub-запросы с `in:readme` по
`"Космос как инфраструктура"`, `"SpaceEconomyPolicy"`,
`"access_modes.csv" "lots.csv"`, а также широкий поиск
`cosmo in:name created:>=2026-09-10` и `kosmo in:name created:>=2026-09-10`.
Кандидаты проверялись по дереву файлов и содержимому, а не только по названию.
Именно широкий поиск по имени обнаружил `Clodex_Cosmoton`.

**НАХОДКА (повторный проход):** запросы GitHub
`"Космос как инфраструктура" in:readme` и `"case_core.py" in:readme`
обнаружили `pmixay/hackathon-1109` и `whatrushki/cosmo-inf`.
Дополнительно проверены свежие `cosmo`/`kosmo` с датой создания от 11.09.
Кандидаты
[TheDoukiDrift/Cosmo-hakaton](https://github.com/TheDoukiDrift/Cosmo-hakaton),
[desquiciadoh/cosmo-nn-2026](https://github.com/desquiciadoh/cosmo-nn-2026),

Ростовские проекты 04–06.09.2026 и другие космические хакатоны исключены как
нерелевантные.
