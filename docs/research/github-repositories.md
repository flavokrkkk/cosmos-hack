## GitVerse

**НАХОДКА (ограниченный отрицательный результат):** внешний поиск
`site:gitverse.ru` по названию кейса, «Космос как инфраструктура»,
«космохакатон», `cosmo`/`kosmo` и именам файлов комплекта не дал подтверждённых
репозиториев нашего Кейса 02. Это не доказывает их отсутствие.

**Ограничение проверки 12.09.2026:** прямое обращение к
[каталогу GitVerse](https://gitverse.ru/explore/repos) и `api.gitverse.ru`
из рабочей среды завершалось таймаутами; Chrome также показал
`ERR_TIMED_OUT`. Через веб-поиск доступны отдельные индексированные страницы,
но внутренний поиск репозиториев полноценно проверить не удалось. По
[документации GitVerse](https://gitverse.ru/docs/gitverse/basics/quick-start/explore/)
публичный поиск доступен без авторизации; наблюдаемая проблема — доступность
сайта из этой среды, а не установленное требование входа.

## Как искали

Проверены:

- поиск репозиториев и коммитов GitHub по точному названию кейса, АНО «КЭП»,
  формулировкам «4 из 8», «общественное ядро», «режим доступа», названиям и
  кодам лотов, именам файлов официального комплекта;
- варианты `cosmohack`, `kosmohack`, `COSMOHACK26`, `space economy`,
  `space portfolio` среди репозиториев, созданных 10–12.09.2026;
- внешняя выдача `site:github.com`, публичные форки официального репозитория и
  ссылки в публичных анонсах серии.

В углублённом проходе добавлены GitHub-запросы с `in:readme` по
`"Космос как инфраструктура"`, `"SpaceEconomyPolicy"`,
`"access_modes.csv" "lots.csv"`, а также широкий поиск
`cosmo in:name created:>=2026-09-10` и `kosmo in:name created:>=2026-09-10`.
Кандидаты проверялись по дереву файлов и содержимому, а не только по названию.
Именно широкий поиск по имени обнаружил `Clodex_Cosmoton`.

Ростовские проекты 04–06.09.2026 и другие космические хакатоны исключены как
нерелевантные.

**Ограничение:** поиск выполнен до стоп-кода 12.09.2026 23:30. Имеет смысл
повторить его после завершения защит 13.09.2026, когда команды могут открыть
репозитории или поисковые индексы успеют их обнаружить.
