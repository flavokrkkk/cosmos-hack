# Событие — КосмоХакатон Нижний Новгород

_База знаний Кейса 02 · [← индекс](README.md)_

## Ключевые факты (ФАКТЫ, из ЛК и хаба)

- **Даты:** 11–13 сентября 2026. **Формат:** гибрид — очно в Нижнем Новгороде (адрес анонсируют
  отдельно, места ограничены) или онлайн из любого региона. **Зачёт один:** кейсы, дедлайны и критерии
  одинаковы для очных и онлайн-команд.
- **Статус:** окружной этап для Приволжского и Уральского ФО в серии «КосмоХакатон» (пять окружных +
  финал). Федеральный проект «Кадры для космоса», нацпроект «Развитие космической деятельности РФ
  до 2030/2036». Организаторы: «Кадры для космоса», Минобрнауки, Роскосмос, РТУ МИРЭА.
- **Призовой фонд:** 1,2 млн ₽. **Команда:** 3–5 человек, к старту укомплектована.
- **Ход события (Положение п. 8.2):** регистрация на площадке → открытие → **презентация кейсов и
  разъяснение требований** → разработка → **чек-поинты с трекерами и экспертами** (консультационно-
  контрольные; баллы за них — только если прямо предусмотрено кейсом, п. 8.4) → отраслевые сессии →
  **стоп-код и загрузка материалов** (после стоп-кода менять репозиторий/модель/видео нельзя, п. 8.5;
  без обязательных материалов могут не допустить к защите, п. 8.6) → **техническая проверка** (запуск
  кода, история репозитория, заимствования, лицензии, п. 8.8) → **публичная защита** (регламент — в
  программе, п. 8.7) → оценивание и награждение. Трекеры помогают с целями, структурой решения и
  защиты, не решая за команду (п. 12.2).
- **Путь в финал (п. 16.1, 4.3, 6.8):** в финал серии (Москва, РТУ МИРЭА, 25–27 сентября 2026)
  приглашаются **первые 4 команды по каждому кейсу** (топ-8 округа в целом); занявшие 1–4 места не
  участвуют в других окружных хакатонах.
- **Официальные правила:** Положение серии — https://нн.космохакатон.рф//storage/docs/regulation.pdf;
  разбор оценки и состава сдачи — [04-rubric-and-delivery.md](04-rubric-and-delivery.md).
