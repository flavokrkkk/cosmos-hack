## Правила ведения

- Один файл — одна тема. Не дублировать: ссылаться.
- Факт — только с URL. Число без источника — помечать «≈ оценка» и на чём основана.
- Гипотеза — всегда с колонкой «как проверить»; после проверки — вердикт, не удаление.
- Кейс-специфичные решения фиксировать в `docs/`, код — отдельными коммитами после старта (AGENTS.md).
- **Полные правила маршрутизации знания** — в [AGENTS.md](../AGENTS.md) (раздел *Documentation and
  knowledge base*) и [CLAUDE.md](../CLAUDE.md). Обязательны для людей и ИИ-агентов: новое знание
  пишется в свой файл в том же ходе; в корне репо новых `.md` не создавать.
